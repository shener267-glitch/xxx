# Pocket Engine

**スマートフォンのブラウザだけで 3D ゲームを作って遊べる、小さなゲームエンジン。**

「3D 空間を編集する → ゲームの仕組みを設定する → Play する → 完成したゲームとして遊ぶ」までを、
インストール不要・サーバー不要でブラウザの中だけで行えることを目指しています。

- 📱 **スマホ縦画面が最優先** — 指で操作しやすい大きなボタン、ボトムシート、専用テンキー
- 🧊 **本物のエンジンらしい編集機能** — ギズモ、Inspector、階層、Undo/Redo、複数シーン
- ▶️ **Play / Stop** — 押すとすぐゲームが動き、停止すると編集前の状態に戻る
- 💾 **ブラウザ内に保存** — IndexedDB に自動保存。ファイルへの書き出し・読み込みも可能
- 🌐 **GitHub Pages で公開できる静的サイト** — バックエンド無し

> 開発の進み具合は下記ロードマップを参照してください。

## 使い方 (スマートフォン)

| 操作 | 内容 |
| --- | --- |
| 1本指タップ | オブジェクトを選択 / 何もない所で選択解除 (小さな物は指の近くをタップしても選べる) |
| 同じ場所をもう一度タップ | 重なっている奥の物を順に選ぶ |
| 1本指ドラッグ | 何もない所: カメラ回転 / 選択中の物: 地面に沿って移動 (移動ツール時) |
| 2本指ドラッグ | カメラの平行移動。ピンチでズーム、ひねって回転 (少し動かすまで反応しないので誤操作しにくい) |
| 長押し | オブジェクトのメニュー (何もない所ならその場所に追加) |
| ダブルタップ | オブジェクトにカメラを寄せる |
| 数値欄 | タップで専用テンキー (四則演算可)、左右ドラッグで値を連続変更 |

画面構成 (縦画面):

```
┌──────────────────────────┐
│ ☰ プロジェクト/シーン ▾  💾 ↶ ↷ ▶Play │ ← 上部バー
├──────────────────────────┤
│                     (軸)  │
│       3D ビュー      🧲    │ ← 右側: スナップ / 座標系 / 複数選択
│                      ◎    │          フォーカス / 視点の保存
│  [問題 2]                 │ ← 設定の問題があるときだけ表示 (タップで「チェック」)
│  [キューブ][◎][複製][削除][…] │ ← 選択中の操作バー (パネルを開いている間は移動/回転/拡大も)
├──────────────────────────┤
│ [選択|移動|回転|拡大]  [+追加] │ ← 主要操作
├──────────────────────────┤
│ シーン | インスペクター | イベント | アセット | 設定 │ ← タブ
└──────────────────────────┘
```

横画面や PC ではパネルが右側に浮かぶ形で表示されます (画面を固定分割しません)。
PC ではマウス (左ドラッグ回転・右ドラッグ平行移動・ホイールでズーム) とキーボードショートカット
(Q/W/E/R ツール、F フォーカス、Ctrl+Z/Y、Ctrl+D 複製、Ctrl+C/V、Ctrl+G グループ化、Del 削除、Ctrl+S 保存、P で Play) が使えます。

## Phase 1 の機能

- **3D ビュー**: WebGL (Three.js)、シャドウ、距離でフェードするグリッド、軸ギズモ、オンデマンド描画 (省電力)
- **オブジェクト**: キューブ / 球体 / 平面 / 円柱 / 円錐 / カプセル / カメラ / ライト (太陽光・ポイント・スポット・環境光) / 空オブジェクト
- **編集**: 追加・選択・複数選択・削除・複製・コピー＆ペースト・名前変更・表示/非表示・ロック・グループ化/解除・親子関係・並び替え
- **変形**: 移動・回転・拡大縮小のギズモ (ワールド/ローカル)、指での直接ドラッグ移動、数値入力、スナップ
- **Inspector**: 名前・種類・位置・回転・サイズ (縦横比固定)・形状・色 (RGB/HEX/パレット)・粗さ・金属感・発光・不透明度・影・ライト/カメラ設定・動作 (コンポーネント)・親子関係
- **Scene**: 階層ツリー・検索・表示/ロック切替・複数シーンの作成/切替/複製/削除/書き出し/読み込み
- **カメラ**: 1本指/2本指/ピンチ操作、視点の保存と呼び出し、上・前・横からの視点、フォーカス
- **Undo / Redo**: すべての編集操作 (シーンごとに履歴を保持、連続操作は1回にまとめる)
- **Play Mode**: ゲームカメラ / 一人称 / 三人称 (仮想ジョイスティック)、自動回転・往復運動コンポーネント、一時停止、全画面、FPS 表示。停止で元に戻る (設定で変更の保持も可)
- **保存**: IndexedDB への自動保存 (使えない環境は localStorage)、プロジェクト一覧 (サムネイル付き)、JSON 書き出し/読み込み
- **エラー処理**: WebGL 非対応の案内、保存失敗・読み込み失敗の通知、Play 中にエラーを起こした動作の自動停止とエラー発生箇所の記録

## Phase 2 の機能 (マテリアル・ライティング・物理)

- **マテリアル**: 標準 / 木材 / 金属 / ガラス / 水 / アンリットのプリセット、色・粗さ・金属感・映り込み・発光・不透明度
- **テクスチャ**: 木目・市松・レンガ・石・タイル・草の模様 (画像不要)、画像の読み込み (IndexedDB に保存、大きな画像は自動縮小)、UV の繰り返し・ずれ・回転
- **ライティング**: 太陽光・ポイント・スポット・環境光、画質に応じた影の解像度
- **環境**: グラデーションの空 / リアルな空 (太陽光の向きと連動) / 単色、空の映り込み (反射)、霧、露出、雨・雪
- **水面**: 波とさざ波が動く軽量なシェーダー (「追加」→「水面」)
- **物理 (cannon-es)**: 物理 (Rigidbody: 動く / 動かす / 固定、重さ・摩擦・跳ね返り・回転固定・重力の有無)、当たり判定 (Collider: 自動 / 箱 / 球 / カプセル / 円柱、すり抜け = トリガー)、シーンごとの物理 ON/OFF と重力設定。物理エンジンは Play 時だけ読み込むのでエディタは軽いまま
- **エディタ表示**: 選択中の当たり判定を緑の枠で表示、「エフェクトのプレビュー」で編集中も水・天候を動かせる

## Phase 3 の機能 (ゲームの仕組み)

- **テンプレート**: メニュー →「プロジェクト」→「テンプレートから作成」で、すぐ遊べる見本 (コインあつめ / ぼうけん) を作成
- **プレイヤー操作**: 歩く・走る (ジョイスティックを大きく倒す / Shift)・ジャンプ (ボタン / Space)・攻撃 (ボタン / E)、三人称 / 一人称 / シーンのカメラ、残機と復活
- **ゲーム用オブジェクト** (「追加」→ ゲーム用オブジェクト): プレイヤー・コイン・回復アイテム・鍵 (持ち物)・敵・NPC・トゲ・セーブポイント・ゴール
- **敵の AI**: 見回り → 近づくと追いかける → 触れるとダメージ。上から踏む・攻撃で倒すとスコア
- **HP・スコア・お金・持ち物・残り時間**: HUD に自動表示。制限時間と時間切れの結果 (ゲームオーバー / クリア) を設定可能
- **NPC との会話**: 近づくと「話す」ボタン。空行でページを区切ったセリフを会話ウィンドウで表示 (会話中はゲームが止まる)
- **画面の UI** (「追加」→ 画面 UI): 文字・スコア表示・ボタン・画像・ゲージ。9 か所の基準位置 + ずれで配置、`{score}` `{hp}` `{timer}` `{var:名前}` などで値を表示。エディタ上でもプレビューされ、タップで選択できる
- **音**: 組み込みの効果音 13 種・音楽 4 曲 (Web Audio で合成、ファイル不要)、音声ファイルの読み込み、シーンの BGM、試聴
- **画面**: タイトル画面 (タイトル・サブタイトル・色・画像)・一時停止メニュー・設定画面 (音量)・ゲームオーバー / クリア画面 (スコア・タイム・もう一度)
- **セーブポイント**: 復活地点の記録と、端末への保存 (タイトル画面の「つづきから」で再開)
- **物理との連携**: プレイヤーのいるシーンでは当たり判定の無いメッシュも自動で固体として扱う (シーン設定で変更可)。物理 OFF でもプレイヤーは動かせる

## Phase 4 の機能 (ノーコードのイベント)

「イベント」タブで **いつ → もし → なら / ちがえば** を選ぶだけで、ゲームの仕組みを作れます (プログラミング不要)。

| 区分 | 選べるもの |
| --- | --- |
| いつ (トリガー) | ゲーム開始・○秒ごと (タイマー)・○秒たったとき・触れた / 離れた・アイテムを拾った・倒した・ダメージを受けた・ジャンプした・話しかけた・ボタンが押された・キーが押された・変数が変わった・条件を満たした |
| もし (条件) | 変数 / スコア / お金 / HP / 経過時間を比べる・持ち物を持っている・オブジェクトが残っている・距離が近い・確率 |
| なら (動作) | 変数を変える・スコア / お金 / HP / 持ち物を変える・効果音 / BGM・お知らせ・会話ウィンドウ・UI の文字を変える・表示 / かくす・消す・動かす・ワープ・複製を出す・飛ばす・待つ・シーン切り替え・ゲームクリア / ゲームオーバー |

- 条件を満たさないときの動作 (「ちがえば」) で分岐、「1回だけ」実行、有効 / 無効、複製、並べ替え
- **変数**: プロジェクト全体で使える値 (初期値付き)。UI の文字で `{var:名前}` と書くと表示できる
- **シーン切り替え**: スコア・お金・HP・持ち物・変数を引き継いで次のシーンへ
- 編集はすべて Undo / Redo 可能。未選択の項目があると決定できない (入力ミスの防止)
- テンプレートにもイベントの見本入り (スコア 100 でお知らせ、村長と話す → 目的が変わる など)

## Phase 5 の機能 (アニメーション・エフェクト)

- **アニメーション** (動作「アニメーション」): 位置・回転・大きさのキーフレーム。スライダーで時刻を選び、
  3D ビューでオブジェクトを動かして「今の姿勢を記録」するだけで作れる。プレビュー再生、くり返し / 1回だけ / 行って戻る、
  なめらか / 一定の速さ、自動再生。プリセット 7 種 (ふわふわ・くるくる・ドキドキ・ゆらゆら・ぴょん・往復・扉が開く)
- **再生・切り替え**: イベントの「アニメーションを再生 / 止める」で切り替え
- **キャラクターの動き** (動作「キャラクターの動き」): 移動の速さから 待機 / 歩く / 走る / ジャンプ / 落下 / 着地 を判定し、
  見た目だけを弾ませる・傾ける (当たり判定には影響しない)。プレイヤー・敵・NPC には最初から付く
- **パーティクル** (「追加」→ エフェクト): 炎・煙・火花・爆発・雨・雪・キラキラ・紙吹雪。量・大きさ・勢い・色を調整、
  エディタでは選択中に動いて見える。画質設定に応じて粒の数を自動で制限
- **エフェクトの動作**: イベントの「エフェクトを出す」「パーティクルを出す / 止める」。敵を倒すと自動で爆発

## Phase 6 の機能 (アセット・部品)

- **読み込み** (アセットタブ →「読み込む」、PC はファイルを画面にドラッグ): 3D モデル (glTF バイナリ `.glb` / 単体の `.gltf`)・
  画像 (PNG / JPEG / WebP など。大きい画像は自動で縮小)・音声 (MP3 / WAV / OGG など)・フォント (TTF / OTF / WOFF / WOFF2)。
  中身を確認し、壊れたファイルはその場でエラー表示
- **3D モデル**: 大きさ・三角形の数・アニメーションの名前を表示し、一覧用の小さな画像を自動で作成。置くと底が地面に来るように配置
  (極端に大きい / 小さいモデルは 2m 前後に調整)。当たり判定はモデルの大きさの箱。モデルに入っているアニメーション
  (歩く・走るなど) を Inspector で選んで Play で再生、「キャラクターの動き」やイベントの「アニメーションを再生」からも切り替え可能。
  骨で動くキャラクター (スキンメッシュ) にも対応
- **画像**: 置くと縦横比に合わせた板になる。マテリアルのテクスチャ・UI の画像にも使える
- **音声**: 置くと効果音のオブジェクトになる。詳細画面から試聴・BGM に設定
- **フォント**: ゲーム画面の文字 (UI) に使える
- **アセット画面**: 小さな画像つきの一覧、種類で絞り込み、名前で検索 (フォルダをまたいで探す)、フォルダ (作成・名前変更・削除・移動)、
  詳細 (プレビュー・情報・使用数)、名前変更、削除 (使っている場所からは自動で外す)。
  カードの ⠿ (PC はカード全体) を 3D ビューへドラッグすると、指を離した場所に置く
- **部品 (Prefab)**: オブジェクトのメニュー →「部品 (Prefab) にする」で、子を含めて保存。アセット画面から何度でも置ける・複製・名前変更・削除。
  置いた物を直して「部品に反映」で部品を更新
- **大量配置**: 部品 / オブジェクトを 格子 (縦 × 横)・一列・円・ばらばら (範囲の中) で最大 500 個まで並べる。向き・大きさのばらつき、
  円の中心を向く、グループにまとめる。1 回の Undo で元に戻せる

## Phase 7 の機能 (地形・空・画面の効果)

- **地形** (「追加」→ 地形・水): 平ら・丘・山・島。Inspector の「ブラシで形を変える」で、
  1 本指でなぞって **盛る / 下げる / なめらか / 平らに** (2 本指でカメラ、ブラシの大きさ・強さはバーで調整、PC はマウス)。
  なぞった 1 回が 1 回の Undo。「形を作り直す」で 丘・山・谷・島・台地 を自動生成 (高さ・起伏の細かさ・別の形)。
  一辺の長さ・細かさ (分割数)、高さと傾きで **砂・草・岩・雪** を自動で塗り分け、ローポリ風の表示
- **地形の当たり判定**: Play でプレイヤー・敵・物理の物が地形の上を歩く / 転がる (物理 OFF でも地形の高さに沿う)。
  エディタでも置いた物や部品・大量配置は地形の表面に乗る
- **水面**: 「地形・水」の「水面」(波打つ水)。島と組み合わせて海に
- **時刻・昼と夜** (シーンの設定 → 時刻・昼と夜): 時刻で太陽が動き、朝焼け・夕焼け・夜の空、**星・月**、
  太陽光の向き・色・明るさ (夜は月の光) が変わる。Play 中に時間を進める (1 日の長さを指定)
- **雲** (量・流れる速さ・高さ・色、時刻で色が変わる)、**雨・雪**、**雷** (稲妻が光って雷の音)
- **画面の効果**: 光のにじみ (ブルーム)・被写界深度 (プレイヤーに自動でピント)・周辺を暗く・あざやかさ・
  コントラスト・色味。画質「低」では使わない。編集中は設定の「エフェクトのプレビュー」で確認
- **イベント**: 「朝になったとき」「夜になったとき」、条件「時刻 (○時〜○時)」、動作「時刻を変える」「天気を変える」

## Phase 8 の機能 (デバッグ・カメラ・タイムライン)

- **デバッグコンソール** (メニュー →「デバッグコンソール」、Play 中は右の 🐞 ボタン、PC は F8 / ` キー):
  - **ログ**: 情報・警告・エラーを種類で絞り込み・検索・コピー・消去。エラーは **発生場所** (例: Play / キューブ) を表示し、
    詳細 (スタック) を開いて「このオブジェクトを選ぶ」で原因のオブジェクトへ移動 (Play 中なら止めてから選ぶ)。
    エラーが出ると 3D ビューの左上に「エラー N」のお知らせ
  - **性能**: FPS (グラフ)・1 フレームの時間・描画の回数・三角形・ジオメトリ / テクスチャの数・JS のメモリ・
    オブジェクト / 物理ボディの数・描画の解像度・画質・画面の効果の有無
  - **道具** (Play 中): シーン切り替え・カメラの切り替え・時刻・HP を回復・最初から
- **オブジェクトの検索** (シーンタブ): 名前だけでなく種類 (カメラ・ライト…)・動作 (敵・アイテム…)・タグでも探せる
  (空白で区切ると両方を含むもの)。検索結果を選ぶとカメラがそのオブジェクトへ向く
- **カメラ**: 視点のブックマーク (Phase 1)、カメラを何台も置いて Inspector の「このカメラから見る」で確認。
  Play 中はイベントの「カメラを切り替える」(何秒かけてなめらかに / ふだんの視点に戻す) で切り替え
- **タイムライン (カットシーン)** (イベントタブ →「タイムライン」): 時刻の目盛りに動作 (カメラの切り替え・会話・移動・
  アニメーションなど、イベントで使える動作すべて) を並べる。スライダーでカメラの切り替えをプレビュー、
  自動で再生・プレイヤーを止める・スキップできる・終わったらカメラを戻す。Play では上下に黒帯。
  イベントの「タイムラインを再生」「タイムラインが終わったとき」で組み合わせられる
- **シーン切り替え**: 上部バーのシーン名から切り替え (Phase 1)、イベントの「シーンを切り替える」(Phase 4)、デバッグの道具

## Phase 9 の機能 (プロジェクト・データの管理)

- **保存**: プロジェクトはこの端末のブラウザの **IndexedDB** に自動保存 (変更の 2.5 秒後・アプリが裏に回ったとき)。
  アセットのファイル本体も IndexedDB に保存
- **パッケージ (.pocket.zip)**: メニュー →「プロジェクトを書き出し (.pocket.zip)」で、データとアセットの本体を 1 つの
  ZIP にまとめて保存。「プロジェクトを読み込み (.zip / .json)」で別のプロジェクトとして追加 (上書きしない)。
  従来の .json (アセットを埋め込み) も読み書きできる
- **すべてバックアップ**: プロジェクト一覧 →「すべてバックアップ (.zip)」ですべてのプロジェクトを 1 つのファイルに。
  そのファイルを読み込むと、中のプロジェクトがすべて追加される (端末の買い替え・データ消失に備えて)
- **自動バックアップ**: 保存のとき、前のバックアップから 10 分以上たっていれば自動で作る (最大 12 個、古い自動のものから消す)。
  メニュー →「バックアップ」で一覧・「今すぐバックアップ」・**この状態に戻す** (戻す前の状態もバックアップ)・
  **コピーとして開く**・削除。設定の「自動バックアップ」で止められる
- **保存領域**: 使用量 / 上限のバー、「データを保護する」(ブラウザがデータを勝手に消さないように persist を要求)
- **複数シーン**: シーン名 →「シーンの管理…」で一覧 (オブジェクト・イベント・タイムラインの数)、開く・名前変更・複製・
  **並べ替え**・開始シーン・書き出し / 読み込み (.json)・削除
- **アセット・部品の管理**: アセットタブの「…」→「他のプロジェクトから取り込む」(画像・音声・モデル・部品を選んで取り込み、
  部品が使っているアセットも一緒に。ID が重なる場合は付け替える)、「使われていないアセットを整理」

## Phase 10 の機能 (ゲームの書き出し)

- **ゲームを書き出す**: メニュー →「ゲームを書き出す…」(またはインスペクターのゲーム設定)。
  名前・**アイコン** (画像から、無ければタイトルの 1 文字目から自動で作る)・作者・バージョン・説明・最初のシーン・
  **画面の向き** (自由 / 縦 / 横)・**画質** (自動 / 低 / 中 / 高)・タイトル画面から始めるか、を決めて書き出す
  - **ZIP で書き出す** (GitHub Pages 用): `index.html`・`pocket-player.js` (ゲームの本体)・`game-data.js`
    (データとアセット)・アイコン・`manifest.webmanifest`・`.nojekyll`・`README.txt`。相対パスだけを使うので
    **展開してリポジトリに置くだけで GitHub Pages で公開できる** (どのサブパスでも動く)
  - **HTML で書き出す**: すべてを 1 つの HTML にまとめる。**ファイルを開くだけで遊べる** (サーバー不要・オフライン可)
  - **新しいタブで遊ぶ**: 書き出したものと同じゲームをすぐに確かめる
- **書き出したゲーム** (エディタを含まない単独のプレイヤー、約 280KB (gzip)):
  タイトル画面 (名前・作者・バージョン)・**設定画面** (音量・**画質**・**全画面**)・ゲーム本体・一時停止 (ボタン / Esc / 別の
  アプリに切り替えたとき)・クリア / ゲームオーバー → もう一度 / タイトルへ・シーン切り替え・つづきから (セーブ)
  - 画面の向き: スマホで合わないときは「画面を縦 (横) 向きにしてください」、PC の横長の画面で縦向きのゲームは中央に縦長の枠で表示
  - ホーム画面に追加するとアプリのように全画面で遊べる (Web App Manifest)
- **全画面でテストプレイ**: メニュー →「全画面でテストプレイ」でタイトル画面から全画面で Play

## Phase 11 の機能 (スマホでの制作を快適に・サンプルゲーム)

新しい機能を増やすより、**実際にスマホでゲームを作るときの気持ちよさ**を優先して、全体を見直しました。

- **3D ビューが隠れない**: パネル (ボトムシート) を開くと、見えている部分の中心にビューが自動で寄る。
  選んだ物がパネルの後ろに隠れたときは見える所まで動かす。パネルを開いている間も選択中の操作バーから移動 / 回転 / 拡大を切り替えられる
- **タッチ操作**: 小さな物は指の近く (約 16px) をタップしても選べる。同じ場所をもう一度タップすると重なった奥の物を順に選ぶ
  (「重なっている物: …」と表示)。2 本指の操作は少し動かすまで反応しない (ピンチ・ひねり・平行移動を区別)。iOS Safari のページ拡大を防止
- **シーン一覧**: パネルの上から直接シーンを切り替え。オブジェクトに役割 (プレイヤー・敵・NPC・コイン・鍵・ゴール・ドア・スイッチ・メインカメラなど) を表示。
  検索・複数選択・追加・メニューを 1 行に。鍵マークはロック中の物だけに表示
- **インスペクター**: 名前と項目へのジャンプ (位置・見た目・動き・当たり判定…) を上に固定。プレイヤー・敵などは「動き」を先に表示。
  あまり使わない設定は「詳しい設定」にまとめた。**地面に置く** (大きさを変えて埋まった・浮いた物の下の面を地面や下の物にそろえる、1 回の Undo で戻る)
- **追加**: 種類へのジャンプと「最近使ったもの」。ゲーム用の **ドア**・**スイッチ** を追加。
  追加した物は見ている場所 (長押しならその場所) の地面の上に、ほかの物と重ならないように置く
- **イベントのひな形**: 「スイッチでドアを開ける」「鍵でドアを開ける」「話しかけると持ち物をもらえる」「敵を全部倒したらクリア」
  「スコアを集めたらクリア」「触れたら別の場所へワープ」を、対象を選ぶだけで作る (ふつうのイベントになるので後から直せる。1 回の Undo で戻る)
- **問題チェック** (デバッグ →「チェック」、または 3D ビューの「問題 N」): プレイヤーがいない・ライトが無い・イベントの「なにに」が未選択・
  消えたオブジェクトや変数を使っている・ゴールに必要な持ち物が手に入らない・消えた画像 / 音・押しても何も起きないボタン などを、
  **原因と直し方**つきで一覧にする。タップでその物やイベントを開き、プレイヤー / ライトはその場で追加できる。Play 時にも件数を知らせる
- **わかりやすいエラー**: よくあるエラー (見つからない・保存容量・通信・音声の読み込みなど) に「ヒント」を付けて表示
- **サンプルゲーム「ポケット城の冒険」** (新しいプロジェクト → テンプレートの先頭): Pocket Engine の機能だけで作った 2 シーンの 3D アクション。
  タイトル → 村 (NPC から鍵をもらう・スイッチで城の門が開く・コイン・ハート・敵・トゲ) → 塔 (鍵で扉を開ける・階段・ボス) → 宝箱でクリア。
  HP・残機・スコア・持ち物の表示、BGM / 効果音、ゲームオーバー → もう一度、まで入っている。
  制作を通して見つかった不具合 (追加した物が原点に置かれる・通知が上の表示に重なる・パネルで 3D ビューが隠れる など) も直した

## 開発

必要環境: Node.js 22 以上

```bash
npm install
npm run dev          # 開発サーバー (同じ Wi-Fi のスマホからも http://<PCのIP>:5173 で確認可)
npm run build        # 型チェック + 本番ビルド (dist/、書き出したゲーム用の dist/player/pocket-player.js も)
npm run preview      # ビルド結果の確認
npm test             # 単体テスト (Vitest)
npm run test:e2e     # E2E テスト (Playwright: スマホ縦画面 + PC)
npm run typecheck    # 型チェックのみ
```

E2E テストは GitHub Pages と同じ **サブパス配信 (`/xxx/`)** でビルド成果物を配信して実行します。
初回は `npx playwright install chromium` でブラウザを取得してください。

## GitHub Pages への公開

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. `main` ブランチにプッシュすると `.github/workflows/deploy.yml` が
   ビルド → 公開 → **公開 URL に実際にアクセスしてスモークテスト** まで自動で行います
3. 公開 URL: `https://<ユーザー名>.github.io/<リポジトリ名>/`

ビルドは相対パス (`base: './'`) なので、どのサブパスに置いても動作します。
また `.github/workflows/ci.yml` がすべてのプッシュで型チェック・単体テスト・ビルド・E2E テストを実行します。

## 構成

```
src/
  core/        データモデル・シーン操作・Undo/Redo・エディタ状態 (DOM/描画に非依存・単体テスト対象)
  components/  ゲームロジック用コンポーネント (自動回転・物理・プレイヤー・敵・NPC・アイテムなど)
  engine/      Three.js による描画・エディタのビューポート・カメラ・ギズモ・タッチ入力
  runtime/     Play Mode の実行環境 (ゲームの状態・音・ゲーム画面の UI。エディタ非依存でゲーム書き出しでも使用)
  storage/     IndexedDB / localStorage への保存、ファイル入出力
  app/         保存サービス・Play の切り替え・ゲームの書き出し
  player/      書き出したゲームの本体 (エディタを含まない。vite.player.config.ts で 1 つのファイルにビルド)
  ui/          画面 (上部バー・ボトムシート・各パネル・入力部品・モーダル)
  styles/      スタイル
tests/         単体テスト
e2e/           E2E テスト
```

設計の詳細は [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) を参照してください。

依存ライブラリは **three** と **cannon-es** (物理。Play 時のみ読み込み) です。3D モデルの読み込み (GLTFLoader) は three 同梱のもので、必要になったときだけ読み込みます (開発用に TypeScript / Vite / Vitest / Playwright)。

## データの保存について

作成したプロジェクトはこの端末のブラウザ内 (IndexedDB) にのみ保存され、外部には送信されません。
ブラウザのデータ削除やプライベートモードでは消えることがあるため、
大切なプロジェクトはメニューの「プロジェクトを書き出し」でファイルに保存してください。
